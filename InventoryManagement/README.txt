Inventory Management (ADO.NET CRUD) - Windows Forms, .NET 8

1. Run Database\setup.sql in SQL Server (creates InventoryDB + Products table + sample rows).
2. Open InventoryManagement.sln in Visual Studio 2022 (needs the ".NET desktop development" workload).
3. Press F5. NuGet restores Microsoft.Data.SqlClient automatically.

If your SQL Server is not "localhost", edit connectionString in Form1.cs.
